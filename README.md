**A calmer way to explore YouTube.**

YouTV is a lightweight YouTube browsing interface for people who want to find videos and channels without getting pulled into endless scrolling. It uses the **YouTube Data API** to search and browse content while keeping the experience focused on what you came to watch.

## Features

- Search for YouTube videos and channels
- Browse videos by category
- Watch videos in the app or open them on YouTube
- View a channel’s public videos
- Keep a local watch history
- Choose a theme and interface language (Three most spoken languages: en-US/es-ES/zh-TW/HK)
- Load more results when you want them

YouTV brings together many familiar YouTube browsing features while aiming for a more intentional viewing experience.

## Designed to discourage doomscrolling

YouTV helps you choose what to watch, watch it, and move on. It provides search and category browsing without centering the experience around an endless stream of recommendations.

## Getting started

You can either download the HTML file and serve it yourself privately or go to our site.

## Notes

- YouTube API quotas, availability, and policies apply.
- Videos and playback are provided by YouTube.
- Your API key and watch history are stored in your browser.
- For a public production site, protect your API key with a secure backend and appropriate key restrictions.
